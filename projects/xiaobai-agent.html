小白 XiaoBai

Xiao Bai · Home Voice AI

會記得家人的家庭語音 AI。
從提醒、記憶、待辦到每日生活回顧，小白把家裡的瑣事整理成可以被理解、被追蹤、被接續的生活脈絡。

Python FastAPI OpenAI Realtime 家庭 AI
家庭內部使用 · 不對外開放

這是什麼？

小白是一個專為家庭打造的語音 AI 生活中樞，可以在手機、平板或電腦瀏覽器開啟，直接用說話的方式互動。它不是客服系統，也不是一般聊天機器人，而是把家人的 Profile、提醒、任務、記憶與生活回顧接在一起的家庭助手。

它能認得不同家人，記住穩定偏好，幫你建立提醒與家庭事項，也會把任務、提醒、記憶、主動推播整理成 Life Log。你可以問「我今天做了什麼？」或「還有什麼沒收尾？」小白會用比較像家人助理的方式，把生活裡散掉的小事收回來。

核心特色

家人 Profile
每位家人都能建立自己的稱呼、頭像、家庭角色、Email、生日與互動偏好，小白會用對應的語氣與記憶空間回應。
Wake Word + 聲紋
說「小白」喚醒後開始對話，聲紋用來判斷現在是哪位家人。聲紋資料保存在本機，可以先跳過，之後再補設定。
Reminder Hub / Task Hub
提醒、採買、家務、待確認事項集中管理。可以用語音建立提醒，也能在首頁看到目前有哪些家庭事項需要處理。
Life Log 生活回顧
把任務、提醒、記憶與主動推送整理成生活時間線，再產生每日摘要，讓使用者可以回頭問「我今天做了什麼」。
Follow-up Radar
找出過期提醒、待確認動作、很久沒更新的任務，讓小白不只是回答問題，也能幫家裡把未完成的事接起來。
主動事件中心
管理背景推播、主動提醒與補講紀錄，讓小白慢慢從被動問答變成會在適合時機提醒你的家庭 AI。

怎麼做到的？

OpenAI Realtime API + WebRTC
瀏覽器直接建立低延遲語音對話，搭配 Web Audio、Wake Word 與 VAD，讓小白能在家庭情境中更自然地被喚醒與回應。
FastAPI + SQLite
後端以 FastAPI 管理 Profile session、提醒、任務、記憶、Life Log 與推播；SQLite 保存本機家庭資料，適合個人與家庭內部部署。
PWA / Web Push / 本機聲紋
支援瀏覽器通知、手機加入主畫面、背景事件串流與本機聲紋資料，讓小白更像常駐在家裡的生活助理。

使用環境

裝置手機、平板、電腦，任何可開現代瀏覽器的裝置
瀏覽器Chrome、Safari、Edge（需支援 WebRTC / Web Audio / Notification API）
連線方式本機 HTTP 或 ngrok HTTPS；手機加入主畫面時建議使用 HTTPS
麥克風需授權瀏覽器使用麥克風
網路需要（語音對話與天氣、搜尋等工具會呼叫外部 API）
開放對象家庭內部使用，不對外開放
關於資料與隱私：API key 不暴露在前端；聲紋、Profile、偏好、提醒與長期記憶保存在本機資料庫。刪除使用者時，會同步清理對話、記憶、提醒、任務、Life Log 與每日摘要，避免舊資料殘留。
