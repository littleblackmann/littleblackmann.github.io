這是什麼？

小白是一個專為家人打造的家用語音 AI 助手，可以用手機、平板或電腦瀏覽器打開，直接用說話的方式互動，不需要打字。它會認識家裡每個人，記住各自的稱呼、偏好與習慣，每次跟你說話都有自己的個性，不是冷冰冰的語音機器人。

小白支援查天氣、問新聞、設提醒、查農民曆、查國定假日和連假、計算與網路搜尋，每天第一次喚醒時也可以主動整理當日資訊，像個貼心的家庭助手。

核心特色

語音即時對話
透過 OpenAI Realtime API，說話不需要按按鈕，語音直接送到 AI，對話流暢自然，就像在跟人說話。
家人共用帳號
支援多位家人各自建立 Profile，進入時選擇自己的頭像，小白會用你設定的稱呼、語氣與偏好回應，每個人有自己的記憶空間。
長期記憶系統
對話後保守萃取值得長期記住的內容，例如飲食偏好、生日、睡眠習慣。也可以直接說「小白，記住我不喜歡太甜的飲料」，小白會記下來。
工具整合
整合中央氣象署天氣、RSS 新聞摘要、農民曆節氣宜忌、台灣國定假日與連假、瀏覽器提醒通知、數學計算、Brave 網路搜尋，小白會自己決定要用哪個工具。
每日簡報
每天第一次喚醒時，小白可以主動整理今日日期、天氣、假日資訊，讓你不需要開口問就能掌握當天概況。

怎麼做到的？

後端架構
Python + FastAPI，以 uvicorn 啟動，支援本機直連或透過 ngrok 讓手機、平板從外部存取，不需要額外安裝 App。
OpenAI Realtime API
語音直接送到 OpenAI 處理，不需先轉文字再送 AI，延遲更低、對話更自然，支援打斷與連續說話。
工具鏈與記憶資料庫
AI 根據問題自動決定呼叫哪個工具（天氣、新聞、農民曆等），記憶與 Profile 儲存在本機 SQLite，每個家人的資料完全隔離。

使用環境

裝置手機、平板、電腦，任何可開瀏覽器的裝置
瀏覽器Chrome、Safari、Edge（需支援 WebAudio API）
連線方式本機 HTTP 或 ngrok HTTPS（供手機遠端使用）
麥克風需授權瀏覽器使用麥克風
網路需要（語音對話與工具查詢會呼叫外部 API）
開放對象家庭內部使用，不對外開放
關於你的資料：語音對話透過 OpenAI Realtime API 傳送，使用者 Profile、偏好與長期記憶儲存在本機 SQLite，不上傳到任何第三方伺服器，開發者完全看不到家庭資料。
