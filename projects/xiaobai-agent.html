想做一個放在家裡的語音助理

最初的想法很單純：做一個能用聲音叫醒、能陪家人處理日常小事的助理。慢慢加上家人 Profile、記憶、提醒、採買和家務，再把這些事情整理成可以回頭看的生活紀錄。

你可以說「三十分鐘後提醒我關火」、「採買清單加一瓶牛奶」，或問「我還有什麼沒收尾？」小白會把相關工具和記憶接起來，讓一句話能接著變成提醒、待辦或查詢結果。

這次更新了什麼？

原本的藍色核心，做得更清楚。保留三欄與軌道感，重新調整光影、面板、文字和手機布局。天氣改成容易看的重點資料，音樂也有直接可用的控制入口。

設定整理成六個分類。日常偏好、語音收音、AI 模型、通知提醒、重要記憶、安全裝置。模型可以用選單挑選，也能填自訂 ID；辨識、對話、發聲和聲音選擇集中管理。

語音新增 OpenRouter 通道。辨識、對話與發聲可透過同一個 OpenRouter key 串接不同模型，同時保留 OpenAI Realtime 作為可切換的通道。

日常可以怎麼用？

一鍵啟動主機→ 選擇家人→ 設定聲紋與收音→ 說「小白」喚醒→ 聊天、查詢、安排日常

電腦上雙擊啟動程式，等服務就緒後會自動開啟頁面。手機、平板也能連到家中的小白主機；家人先選自己的 Profile，再使用對應的偏好和記憶。

小白現在有哪些功能？

家人 Profile 與長期記憶
家人各自保存稱呼、頭像、互動偏好與重要記憶。選好 Profile 後，用本機喚醒詞與聲紋確認使用者，再接續對話。
可選模型的語音通道
OpenRouter 串起語音辨識、對話／家庭工具、語音發聲；OpenAI Realtime 通道也保留。可以調整不同階段的模型與聲音，沿用家人的工具和記憶。
收音設定與插話
可選麥克風、做六秒底噪校正，並區分耳機與喇叭模式。喇叭播放時可按鈕打斷；耳機模式加入說話打斷，讓對話控制更直接。
提醒、採買與家務
用語音建立提醒與家庭事項，在首頁查看提醒、採買、家務及待確認動作。需要核對的操作會保留確認流程。
主機上的音樂
可說歌名、歌手或音樂類型，也能在首頁點歌、暫停、繼續、切歌和調整 YouTube Music 音量。會區分操作已送出與已確認播放，失敗時說明原因；音樂由小白主機播放。
天氣、新聞與生活查詢
查天氣、新聞、時間、農曆、假日或搜尋日常資訊。首頁保留今日簡報，溫度、降雨與下一個提醒可以直接看到。
生活回顧與主動提醒
將任務、提醒、記憶和主動推送整理成 Life Log 與每日摘要。也能找出過期提醒、待確認動作和久未更新的任務，接續還沒收尾的事。
整理過的設定介面
六個分類搭配模型選單，個人偏好與共用 AI 設定分開儲存。切換分類保留草稿，儲存失敗保留輸入；手機和電腦使用同一套設定入口。

怎麼做到的？

OpenRouter / OpenAI Realtime
OpenRouter 採辨識 → 對話／工具 → 發聲的分段流程；OpenAI Realtime 保留 WebRTC 即時通道。兩種方式共用家庭工具、Profile 與記憶，不預設使用 Google AI 模型。
FastAPI + SQLite
Python 後端管理家人 session、提醒、任務、記憶、生活回顧和推送；家庭資料由本機保存。音樂操作在背景執行，並避免同時操作播放器造成衝突。
瀏覽器介面 + 本機喚醒
Web Audio 處理麥克風與語音播放，喚醒與聲紋在本機運作；PWA 與 Web Push 提供加入主畫面和背景通知的入口。

使用環境與目前進度

小白主機Windows 電腦執行 Python 後端；音樂控制使用主機上的 YouTube Music App
操作裝置電腦、手機、平板瀏覽器；目前主要驗證 Chrome／Chromium 環境
連線方式主機本機頁面可使用 localhost；手機連線需配置 HTTPS 並授權麥克風
AI 服務使用所選的 OpenRouter 或 OpenAI API 憑證；雲端模型需要網路，API 費用另計
開放對象家庭內部使用，目前不提供公開下載

目前是 C112 開發版。首頁、六分類設定與音樂控制已完成程式更新，桌面／手機介面與模擬語音、控制流程已驗證。真實收音、音色、延遲及歌曲播放仍待實機驗收；這裡展示的是開發進度。

關於資料與隱私：聲紋、家人設定與生活紀錄在本機保存，API key 由後端保管。使用雲端語音與 AI 功能時，所需錄音、文字及相關記憶脈絡會傳送到選定的 AI 服務處理；小白並非完全離線系統。
