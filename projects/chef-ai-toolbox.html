這是什麼？

AI 廚房（Chef AI Toolbox）是一款 Android 料理助理：用現有食材整理食譜、拍照估算餐點營養，再把完成的內容收進手機料理本。

新版以深藍底、青綠到紫色的漸層和柔和光暈，搭配分步引導，把選食材、口味與確認菜單拆成清楚的三個階段。可以回頭修改，切換頁面也保留這次的選擇。

使用自己的 ChatGPT 會員，在官方登入頁授權後回到 APP，無需複製 API Key。APP 本身免費，ChatGPT 訂閱另計；目前這條整合需要符合資格的 Plus／Pro 與方案用量授權，可用模型及額度依帳號實際結果為準。

三大功能

01
冰箱食譜生成器
分類挑選、搜尋或自訂手邊食材，再選家常／日式／西式／低卡／快手風格、1–8 人份與 1–3 道菜。確認後生成食材用量、步驟與料理提醒，多道食譜可滑動或按鈕切換。
02
拍照看熱量
拍照或透過系統相簿選圖，補充份量與烹調資訊，再用支援圖片的模型估算熱量、蛋白質、碳水與脂肪。照片無法準確量出油量和份量，數值只供日常參考，不作為醫療或精準飲食依據。
03
手機料理本
完整完成的食譜與熱量分析保存在本機，回看不必重新生成。支援搜尋、單筆及批次刪除，清空前會確認；兩類紀錄各保留最近 50 筆，超過時移除最舊紀錄。取消或失敗的生成不會當成完成紀錄保存。

帳號與日常使用

自己的會員，自己的模型
Continue with ChatGPT 會開啟官方登入頁。回到 APP 後，等帳號、方案授權與模型清單載入完成即可使用；可切換帳號、選模型、重新登入及登出。瀏覽器收到登入回應不等於 APP 已連線完成。
一步一步，不用一次填完
食譜確認前可返回改食材與偏好；照片選好後再補充備註。生成時可以取消，遇到額度、網路或服務問題會顯示提示，再決定重試或查看帳號。
料理紀錄留在手機
原生 Kotlin／Jetpack Compose 介面，歷史紀錄可離線回看；使用 AI 與檢查更新需要網路。登入資料由 Android Keystore 加密保存，APP 不提供手動 API Key 設定。

新版通知與這次更新

v0.9.2 修正部分裝置收到回應卻無法讀取食譜串流的問題，改善錯誤提示，沿用新版漸層介面與三步料理流程。已在 MSI 保留既有登入並收到食譜文字；完整保存、真人照片分析與各廠牌相機仍持續實機驗收。

支援更新功能的版本會在開啟時檢查新版，背景約每 12 小時檢查，實際時間由 Android 安排。Android 13 以上可在設定允許更新通知；也能隨時手動檢查，未允許通知仍可在 APP 內看到更新提示。

更新以 GitHub 的正式 Release 與 APK 為準，推送原始碼不會直接通知。收到提示後開啟版本頁下載、覆蓋安裝；較舊、沒有更新功能的版本，請從這個頁面手動下載。

資料與隱私：料理紀錄與餐點照片保存在手機，登入憑證在本機加密。啟動 AI 時，這次的食材、備註或照片會直接送往 OpenAI，沒有開發者 AI 中繼伺服器；服務端處理及留存依 OpenAI 政策。檢查版本會連線 GitHub。登出會清除本機登入；若遠端撤銷未成功，可到 ChatGPT 管理連線。
