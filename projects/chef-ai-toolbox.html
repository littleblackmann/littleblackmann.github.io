這是什麼？

廚師 AI 工具箱是一款 Android 料理助理 App，有三個核心功能：冰箱食譜生成器、熱量雷達、我的紀錄。

跟一般 AI 食譜 App 最不一樣的地方 — 食譜不是機器直接丟給你，而是經過真廚師反覆調教的 AI 出的，每個步驟都會告訴你「為什麼這樣做」：醃肉順序、翻鍋時機、醬油沿鍋邊淋的原因。像一個真的會做菜的朋友站在旁邊講給你聽。

App 本身完全免費。沒有訂閱、沒有廣告、沒有後端伺服器。你用自己的 OpenAI API Key，AI 費用直接進你的帳戶，開發者一分錢都不碰。

三大功能

🥬
冰箱食譜生成器
從六大分類（蔬菜、肉類、海鮮、蛋奶豆、五穀、調味料）選出冰箱現有食材，搭配料理風格（家常／日式／西式／低卡／快手）和幾人份，AI 立刻出 1–3 道食譜。每道菜附精確克數、5 步驟、廚師眉角，出來的菜名也有記憶點。
🔥
熱量雷達
拍一張料理照片（或從相簿選），AI 辨識菜色後估算熱量、蛋白質、碳水、脂肪，並給 2–3 句具體可執行的降熱量建議。誤差約 ±15%，供參考用，不是醫療建議。
📚
我的紀錄
每次生成的食譜和熱量分析都自動存進手機本機，下次想看直接翻，不用重複扣 API 費用。最多 50 筆，超過會自動淘汰最舊的，不佔空間。

怎麼做到的？

AI 串流食譜生成
呼叫 OpenAI Chat API，搭配由真廚師反覆調教的 system prompt，串流輸出每一個字。食譜的「廚師眉角」段落是 prompt 設計的核心，不是通用的食譜模板。
視覺辨識熱量分析
使用 GPT-4o Vision 分析料理照片，辨識菜色後估算熱量與營養成分，並給出具體可執行的降熱量建議。
本地優先架構
Room 資料庫儲存食譜與熱量紀錄，DataStore 存 API Key，Coil 處理熱量分析的縮圖。App 完全沒有後端伺服器，所有資料都在你的手機裡。

安裝提醒：因為是個人作品、沒有上架 Google Play，第一次安裝時 Android 會跳出「未知來源」警告，這是系統的正常行為，不是 bug。在設定中允許「安裝未知應用程式」即可。

第一次開啟：需要輸入你自己的 OpenAI API Key（格式：sk-開頭的一串字）。沒有 Key 的話，到 platform.openai.com 申請一把，先儲值 5 美金試水溫，一般家庭用一個月大概 NT$ 30–80 左右。
隱私保證：App 沒有後端伺服器。你輸入的食材、拍的照片，直接送到 OpenAI，不經過開發者。你的 API Key 只存在你手機的本地儲存，永遠不會上傳到任何地方。食譜紀錄、熱量紀錄都只在你的手機裡，App 開發者完全看不到。
