這是什麼？

今日紫微是一款把傳統「紫微斗數」與現代 AI 結合在一起的個人化運勢 App。只要輸入出生年月日時，App 就會自動排出你的專屬命盤，每天計算當日的流日運勢，再由 AI 用自然語言寫成你看得懂的解讀。

命盤計算在手機本機完成，完全離線。AI 解讀部分則使用你自己的 OpenAI API Key，資料不經過任何第三方伺服器，費用也由你自己掌控。

怎麼做到的？

紫微斗數演算法
依出生年月日時推算十二宮宮位與星曜落點，再根據今日農曆日期計算流日大限，所有計算在手機本機完成，完全離線。
AI 解讀整合
將命盤摘要與流日狀態組成 prompt，透過你自己的 OpenAI API Key 呼叫 GPT 生成個人化文字。資料直達 OpenAI，不經過任何第三方。
本機資料儲存
Room 資料庫儲存家人命盤與詢問記錄，DataStore 存 API Key 與偏好設定，全部只在手機裡，開發者看不到任何東西。

系統需求

作業系統Android 8.0（API 26）以上，建議 Android 10+
iOS 支援不支援（iPhone / iPad 無法安裝）
檔案大小約 2.4 MB
網路命盤計算不需要；AI 解讀查詢時需要
OpenAI Key需自備一組（App 內有申請教學，每次查詢約 NT$0.03 以下）
費用App 本身完全免費、無廣告、無內購
安裝提醒：因為是個人作品、沒有上架 Google Play，第一次安裝時 Android 會跳出「未知來源」警告，這是系統的正常行為，不是 bug。請在設定中允許「安裝未知應用程式」即可。
關於你的資料：命盤計算在手機本機進行，不上傳給任何人。進行 AI 查詢時，App 會將命盤摘要透過你自己的 API Key 傳送給 OpenAI（不傳給 App 開發者）。家人姓名與出生資料儲存在你的手機，開發者完全看不到。
