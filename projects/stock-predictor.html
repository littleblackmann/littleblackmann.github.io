這是什麼？

一套免費的 Windows 台股研究工具。輸入股票代碼或名稱，例如 0050、2330，就能查看最近完整收盤行情，以及未來 1、3、5 個交易日相對於目前收盤價的漲跌機率。每個期限分開分析，搭配歷史驗證一起看。

1／3／5 個交易日
各自顯示上漲機率、方向與目標收盤日期。交易日會避開週末與休市日，不是連續三天的逐日價格預測。
把不確定說清楚
機率接近五五波，或歷史驗證未優於基準時，顯示「方向不明」。不會為了給出答案就硬選漲或跌。
歷史驗證一起看
列出歷史模型命中率、多數方向基準與測試筆數。機率與驗證結果分開呈現，方便判斷這次分析有多少參考價值。
選用 AI 整理新聞
填入自己的 OpenRouter API Key，搜尋、選擇模型整理近期新聞；清單可更新，也能查看參考價格。新聞分析獨立呈現，不直接改動模型機率。
K 線與大字模式
互動式 K 線、均線與成交量，可縮放、拖曳。大字模式讓日期、機率和重點說明更容易閱讀。
自選清單與追蹤記錄
收藏常看的股票，從總覽查看已有分析。各期限的預測留下記錄，等目標日完整收盤後補上結果，方便回頭檢查。

v1.7.0 把短線分析重新整理：先確認資料是完整收盤，再分別評估不同期限，讓畫面上的數字和日期更容易核對。

明確標示「資料截至」和「預測目標」。盤中尚未完成的日 K 不會拿來當作當日收盤資料。
更嚴謹的歷史檢查
依時間先後分開訓練、機率校準與測試，並隔開會重疊的預測期間。歷史資料的表現仍不代表未來會準。
AI 模型清單可以更新
在設定搜尋模型名稱或廠商，一鍵更新 OpenRouter 清單與價格資訊。更新清單會保留你原本選用的模型。

怎麼開始使用？

  1. 下載完整 ZIP，先解壓縮。開啟解壓後資料夾中的「台股預測分析系統.exe」。整個資料夾要一起保留，不要只搬走 EXE。
  2. 輸入股票代碼或名稱，按「短線分析」。第一次需要下載歷史資料與建立模型，請等待進度完成。
  3. 先核對日期，再看機率與歷史驗證。上漲機率是模型估計，不是保證；「方向不明」也是一個有用的結果。
  4. 需要新聞解讀，再設定 OpenRouter。API Key 為選填；不填也能做量化分析。AI 模型費用由 OpenRouter 依實際用量計收。

開啟軟體後會檢查新版，也可以到設定 → 關於／更新手動檢查，跟著提示下載並重新啟動。目前使用完整更新包。v1.7.2 將更新包縮小約 48%，並加入下載中斷重試、保留進度與續傳；也保留手動檢查修正。

舊版的續傳功能要在成功升級後才會生效。如果更新仍無法完成，可用瀏覽器從這一頁下載完整 ZIP，先關閉舊程式，再解壓到新資料夾後啟動。程式會讀取同一個 Windows 使用者的設定、自選清單與記錄。
