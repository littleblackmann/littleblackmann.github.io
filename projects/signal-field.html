這是什麼？

很多科幻 HUD 桌布的數字只是裝飾；SIGNAL FIELD 的每一格都有實際來源。它用程序化生成的 WebGL2 線框引擎當核心，將電腦的即時狀態整合成安靜、細緻的桌面監測介面。

核心遙測

CPU、記憶體、GPU、VRAM、溫度、功耗、時脈、風扇與各邏輯核心的獨立負載。

系統與網路

硬碟用量與即時讀寫、網路上下行和延遲、前六名 CPU 程序、60 秒負載走勢。

環境監測

天氣、體感、風、濕度、空品、PM2.5、紫外線、日出日落與行事曆。

音訊反應

原生音訊 API 驅動的左右聲道電平、48 格頻譜、三頻能量與全息體呼吸效果。

全息引擎

8000+ 條即時繪製線段、掃描平面、滑鼠視差與五組配色，不用影片或 3D 模型檔。

實際警戒

GPU 過熱、硬碟不足、記憶體過高或延遲異常時才會亮起警戒，不做無意義的假警報。

30 秒安裝

  1. 下載並解壓縮壓縮檔。
  2. 開啟資料夾後雙擊 INSTALL.cmd。
  3. 依畫面指示安裝；沒有 PowerShell 7 時，安裝程式會先詢問是否使用 winget 安裝。
  4. 打開 Wallpaper Engine，重新整理「我的專案」，選擇 SIGNAL FIELD。

系統需求與隱私

系統Windows 10 / 11、Wallpaper Engine，以及支援 WebGL2 的顯示卡。
遙測 agent完整即時硬體 HUD 需要 PowerShell 7；安裝器會先詢問才安裝。
顯示卡NVIDIA 可顯示最完整的 GPU 溫度、功耗、時脈、風扇與 VRAM；AMD／Intel 仍可使用，但部分欄位可能無數據。
網路天氣與空氣品質使用 Open-Meteo；自動定位使用 ipapi.co，也可在桌布設定自行填入座標。
資料安全遙測 agent 只監聽本機 127.0.0.1，只讀取這台電腦的資料，不會將硬體或程序資料上傳。
小提醒：壓縮檔不含私人行事曆設定。若要在桌布顯示行程，可在安裝後的設定檔填入自己的 ICS 日曆網址；不要將私人 ICS 網址分享給他人。

Steam 訂閱版：啟用完整遙測

Steam Workshop 能直接安裝桌布，但基於 Windows 安全機制，不能自行啟動本機程式。第一次想顯示 CPU、GPU、硬碟、網路與程序資料時，下載一次本機 agent 即可；它會在登入時自動啟動，之後 Steam 訂閱版與完整下載版都會自動連線。
