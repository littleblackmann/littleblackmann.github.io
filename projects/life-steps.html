這是什麼？

人生步數是一款結合「真實計步器」與「人生養成」的手機小遊戲。你用手機走路，每一步都會推進角色的人生 — 從嬰兒到死亡，一生 25 天。

沒有戰鬥、沒有付費、沒有廣告，是一個讓你重新思考「走路」這件事的療癒小品。

核心特色

🚶
走路 = 推進人生
用 Android 計步器計算步數，步數累積會推動角色的時間。你走得越多，角色的人生越往前。
🎲
職業抽獎 & 稀有度
成年時隨機分配職業，共 14 種 + 3 個隱藏彩蛋。稀有度分 6 級（普通 / 稀有 / 珍貴 / 史詩 / 傳說 / 神話），有人一輩子抽不到神話。
🎁
抽獎揭曉動畫
禮物盒 → 開箱 → 職業彈跳，粒子特效隨稀有度升級。神話等級特效最爽。
🔄
輪迴系統
死後重新開始，累積的圖鑑、成就、紀錄都保留。你可以一輩子一輩子地收集不同職業。
🏆
成就 & 隱藏彩蛋
16 個成就即時通知。隱藏彩蛋如「步行之神」「壽星」「精準機器人」，觸發條件自己發現。
🎨
手繪 Q 版視覺
角色與場景全用 Compose Canvas 自繪，7 個生命階段各自的外觀與配色。圓潤、可愛、療癒，不要科技感。

怎麼做到的？

計步器
使用 Android Sensor API 的 STEP_COUNTER + STEP_DETECTOR 雙感測器，搭配 Foreground Service 在背景持續記步。
資料儲存
Room 做本地資料庫（步數、生命、圖鑑紀錄），DataStore 存使用者偏好設定。
UI & 視覺
Jetpack Compose 宣告式 UI，角色與場景用 Compose Canvas 自繪，Coroutines + StateFlow 處理狀態。
